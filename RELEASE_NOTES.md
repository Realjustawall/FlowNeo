# FlowNeo v1.3.0

FlowNeo v1.3.0 focuses on presentation, documentation, and a consistent English user experience while preserving the extension's existing helper behavior.

## What's new

- Fully English extension description and popup copy.
- Fully English help page and documentation.
- Redesigned FlowNeo branding and polished modern popup UI.
- Vazirmatn/Vazir set as the primary UI typeface.
- Updated version labels and manifest metadata.
- Developer attribution standardized to `RealJustAWall`.
- Added complete installation, usage, permissions, architecture, and security notes.
- Added a release ZIP suitable for Chrome's **Load unpacked** workflow after extraction.

## Installation

1. Download `FlowNeo-v1.3.0.zip`.
2. Extract it.
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode**.
5. Click **Load unpacked** and select the extracted folder.
6. Open FlowNeo, enable the helper, and reload any open Google Flow tab.

## Notes

FlowNeo is an independent project and is not affiliated with Google. The existing helper engine communicates with `flow.cfcnode.com` for its remote Flow configuration specification. Review the source and permissions before installation.
